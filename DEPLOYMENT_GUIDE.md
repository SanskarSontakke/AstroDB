# AstroDB — Supabase & Vercel Production Deployment Guide

This guide walks you through deploying **AstroDB** to **Supabase** (PostgreSQL + pgvector database) and **Vercel** (Serverless Next.js API & Agent Gateway).

---

## 📋 Step 1: Set Up Supabase Project

1. Go to [https://supabase.com](https://supabase.com) and create a new project (e.g., `astrodb-production`).
2. Once the project is provisioned, go to the **SQL Editor** in the Supabase Dashboard.
3. Open the file [`supabase_schema.sql`](file:///C:/Users/SanskarSontakke/AstroDB/supabase_schema.sql) from this repository, copy its entire contents, paste it into the SQL Editor, and click **Run**.
   - This automatically enables `uuid-ossp` and `vector` (`pgvector`).
   - Creates all 16 relational tables with spatial and spectral indexes.
   - Installs the `match_celestial_objects` vector RPC and `execute_astro_sql` read-only RPC.
   - Applies Row Level Security (RLS) public read policies.

## 📦 Step 2: Ingest Astronomical Data into Supabase

You have two easy methods to seed all 15,482 records:

### Method A: Supabase SQL Editor (Fastest)
1. In the Supabase dashboard, open the **SQL Editor**.
2. Open the file [`supabase_seed_data.sql`](file:///C:/Users/SanskarSontakke/AstroDB/supabase_seed_data.sql) generated by our pipeline.
3. Paste the contents into the SQL Editor and click **Run**. All 16 tables will be populated with referential integrity.

### Method B: Automated Python Migration Script
Run the automated migration pipeline using your Supabase credentials:
```bash
pip install supabase httpx
python scripts/migrate_to_supabase.py "https://YOUR_PROJECT_ID.supabase.co" "YOUR_SERVICE_ROLE_KEY"
```

## 🧠 Step 3: Generate pgvector Semantic Embeddings (Optional but Recommended)

To enable natural language semantic search for your AI agents (e.g., *"Find rocky exoplanets with ocean signatures within 40 light years"*):

```bash
# Set your environment variables
set OPENAI_API_KEY=sk-proj-...
set NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT_ID.supabase.co
set SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVICE_ROLE_KEY

# Run the embedding pipeline
python scripts/generate_embeddings.py
```
This builds contextual text summaries across all celestial bodies and stores 1536-dimensional embeddings in `celestial_embeddings`.

## ⚡ Step 4: Deploy to Vercel

### Option A: Deploy via GitHub (Recommended)
1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: initial AstroDB production release"
   git remote add origin https://github.com/your-username/AstroDB.git
   git push -u origin main
   ```
2. Go to [https://vercel.com/new](https://vercel.com/new) and import the `AstroDB` repository.
3. In the **Environment Variables** section, configure:
   - `NEXT_PUBLIC_SUPABASE_URL`: `https://YOUR_PROJECT_ID.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`: `YOUR_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`: `YOUR_SUPABASE_SERVICE_ROLE_KEY`
   - `OPENAI_API_KEY`: `sk-proj-...`
   - `ASTRODB_API_KEY`: `astro_sec_live_key_...` (choose any secure random string)
4. Click **Deploy**. Your AstroDB Web Portal and AI Agent API will be live on `https://your-project.vercel.app`!

### Option B: Deploy via Vercel CLI
```bash
npm i -g vercel
vercel login
vercel --prod
```

## 🤖 Step 5: Connect AI Agents

### 1. Claude Desktop (Model Context Protocol)
Add this to your `claude_desktop_config.json` (`%APPDATA%\Claude\claude_desktop_config.json` on Windows):
```json
{
  "mcpServers": {
    "astrodb": {
      "command": "python",
      "args": ["C:/Users/SanskarSontakke/AstroDB/sdks/mcp_server.py"],
      "env": {
        "ASTRODB_API_URL": "https://your-project.vercel.app/api/mcp",
        "ASTRODB_API_KEY": "your_api_key_here"
      }
    }
  }
}
```

### 2. Cursor IDE (.cursor/mcp.json)
```json
{
  "mcpServers": {

      "env": {

        "ASTRODB_API_KEY": "your_api_key_here"

```

### 3. Python AI Agents (LangChain, AutoGen, CrewAI)
```python
from sdks.python.astrodb_client import AstroDBClient

client = AstroDBClient(
    base_url="https://your-project.vercel.app",
    api_key="your_api_key_here"
)

# Search exoplanets with semantic query
planets = client.search("habitable zone Earth analogues within 100 light years")

# Query specific object dossier
dossier = client.get_object("TRAPPIST-1 e")
```
